# Product Assets & Templates Directory

This directory stores the source templates, checklists, worksheets, and spreadsheets for the **Fresher Job Application Kit (Free MVP)**.

## Planned Component Structure
- `templates/`: Source `.docx` and reference `.pdf` files for the single-column ATS resume.
- `checklists/`: Source markdown and PDF assets for "What to Remove" and "Indian Fresher Resume Audit".
- `worksheets/`: Source assets for the 10-Minute Job-Description Keyword Tailoring Worksheet.
- `guides/`: Source assets for the Naukri Profile Optimization Checklist and Project Bullet Formulas.
- `tracker/`: Source `.xlsx` and Google Sheets template links for the Job Application Tracker.
- `dist/`: Packaged `.zip` releases ready for public distribution once approved by Founder Rohit.

*Note: No final customer-facing assets are published or distributed without explicit Founder review and sign-off.*
