# Content & Creative Asset Directory

This directory stores drafts, scripts, visual layouts, and distribution copies for value-first educational content.

## Structure
- `linkedin/`: Drafts of text posts and PDF carousel source slides.
- `reddit/`: Educational long-form diagnostic posts tailored for `r/developersIndia` and `r/Indian_Academia`.
- `video_scripts/`: 45-60 second scripts and visual storyboards for YouTube Shorts and Instagram Reels.
- `web_guides/`: Search-friendly markdown guides and articles.

*Strict Boundary: No content is to be published without Founder review and approval.*
