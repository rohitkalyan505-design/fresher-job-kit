# Analytics & Metrics Directory

This directory tracks the performance of content distribution, product adoption, and business indicators.

## Tracked Metrics
- `content_metrics.csv`: Platform, post headline, publish date, impressions, saves/bookmarks, clicks to free kit.
- `download_metrics.csv`: Date, unique landing visitors, completed kit downloads, conversion rate.
- `feature_requests.csv`: Raw log of user feature requests categorized by theme (reviews, domain templates, cold outreach, etc.).
- `revenue_ledger.csv`: Formal accounting of upfront costs (strictly ₹0), waitlist commitments, and future revenue.
