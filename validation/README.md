# Validation Data & User Feedback Directory

This directory stores qualitative and quantitative validation records, raw survey responses, and feedback transcripts.

## Structure
- `user_feedback/`: Anonymized notes from direct user DMs, comments, and email replies.
- `survey_responses/`: CSV exports and summaries of the 3-question embedded kit survey.
- `usability_testing/`: Notes from testing `.docx` files across Word, Google Docs, and LibreOffice.
- `feature_clusters/`: Log of unprompted feature requests to identify real demand patterns for future paid modules.
