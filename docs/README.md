# Documentation & Guidelines Directory

This directory stores architectural standards, document formatting guidelines, quality assurance protocols, and internal playbooks.

## Structure
- `style_guide.md`: Typography, margin, spacing, and phrasing standards for all product templates.
- `qa_checklist.md`: Step-by-step verification protocol for cross-platform document rendering (.docx, Google Docs, LibreOffice).
- `founder_briefings/`: Periodic progress memos and decision escalation requests for Founder Rohit.
